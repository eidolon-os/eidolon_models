# pplx-decider 图片快速决策测试

日期：2026-10-13。服务：A100 6 号卡上的 SGLang（主干 `d62b9c2`），即 9981 端口的 pplx-decider-v1.1-27B 服务。零样本，模型不做任何训练。
脚本、图片、逐题结果在 `laya/train/runs/pplx-vision-20261013/`（不入库）。

## 结论

**可用。** 图片判断和文字判断走同一个 `/v1/systemone` 接口，在请求里加一个 `images` 字段即可。本次 96 张图、258 道题：

| 情况 | 准确率 |
|---|---|
| 带图，按训练时的上限缩到 512×512 以内 | **98.8%**（255/258） |
| 带图，放宽到 1024×1024 以内（截图、图表、实拍照片） | 99.2%（129/130） |
| 不带图，对照 | 36.0%，接近瞎猜 |
| 中文截图做了旋转、模糊、压缩、眩光的重度退化 | 512 下 97.6%，1024 下 100% |

- **置信度很能说明问题。** 最大概率不低于 0.8 的回答占 97.7%，全部正确；错题的最大概率都在 0.74 以下。
- **速度。** 512 上限下一张图问一道题约 250 毫秒，三道题约 510 毫秒。时间包含从 Mac 经公网的往返，约 70 毫秒。
- **主要保留。** 测试图要么是图标式的清晰照片，要么是代码生成的截图，只有一张是真实拍摄的屏幕照片。真实的事故、火灾、聚集现场照片没有测，上线前要用真实样本再测一轮。

|---|---|---|---|
| 真实照片 | 99.2% | 未测（原图就是 512） | 35.2% |
| 中文截图 | 98.8% | 98.8% | 39.3% |
| 图表与计数 | 100% | 100% | 27.5% |
| 实拍屏幕照片 | 5/6 | 6/6 | 4/6 |

错题：

- **鸟巢里的蓝色鸟蛋被判成"是食物"**，最大概率 0.74。
- **刷单聊天里"先垫付货款"没被判成"转账汇款"**，最大概率 0.66；放宽到 1024 后答对。这道题的标准答案本身有些模糊。
- **实拍流程图"四星属于哪一档"在 512 下答成"重大"**，最大概率 0.60；放宽到 1024 后以 0.9998 答对"较大"。原图 1500×2000，缩到 512 面积后小字看不清。
- 1024 下另有一道车祸帖子的情绪判成"中性"，最大概率 0.50；512 下是对的。帖子末尾是"大家路过注意"，情绪确实介于中性和负面之间。

| 退化 | 512 | 1024 |
|---|---|---|
| 轻度 | 83/84 | 84/84 |
| 重度 | 82/84 | 84/84 |

错题仍是上面那两道标准答案模糊的题，而且最大概率都低于 0.8。

## 速度与成本

pplx 每道题都要把图片和文字整段重读一遍，所以同一张图问几道题，图片就算几次。

| 图片上限 | 每张图问几道题 | 延迟 p50 | 输入 token |
|---|---|---|---|
| 不带图 | 3 | 173 ms | 312 |
| 512×512 | 1 | 252 ms | 366 |
| 512×512 | 3 | 514 ms | 1,086 |
| 1024×1024，750×1000 的截图 | 3 | 908 ms | 2,443 |
| 1024×1024，实拍照片 | 6 | 2,045 ms | 6,842 |

512 上限下一张图每道题约多 260 个 token。按 A100 上每秒约 4,500 个 token 的预填上限估算，最多每秒约 12 道"一图一题"。

## 怎么用

1. 请求里加 `"images": ["data:image/jpeg;base64,..."]`，也可以填图片网址。其余字段和文字题完全一样。
2. **图片先在客户端缩到 512×512 面积以内**，宽高等比缩放。这是 pplx 训练和官方评测的设置，SGLang 不会替你缩。
3. **按置信度分流，低置信时再提高分辨率。** 先用 512 问。最大概率低于 0.8 的题，用 1024 再问一次；还低于 0.8 就转人工。
   按本次结果，这样自动放行的回答没有一道错。实拍流程图那道题就是在 1024 下补对的。
4. **每张图少问几道题。** 题数决定成本；能用一道选择题问完的，不要拆成好几道是否题。
5. 和文字判断一样，判断标准要写进题目，门槛卡在最大概率上，不要用 `confidence` 字段。

## 局限与下一步

- 没测真实的突发事件照片和视频，比如事故、火灾、积水、人群聚集、横幅标语，这是舆情场景最需要的。下一步应拿几十张脱敏的真实图片测。
- 没有和 pplx 官方实现做图片对拍，6 号卡被 SGLang 服务占着。文字题对拍是 99.8% 一致，图片路径没有验证。
- 每次请求只放了一张图。多图对比，比如前后对照，没有测。
- 合成截图和图标照片偏干净；真实截图常带水印、表情、多层转发，难度更高。

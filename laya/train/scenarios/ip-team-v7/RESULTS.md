# v7 实验结果：开发集改善，泛化仍不合格

2026-09-28。已完成数据生产、逐条审核、冻结切分、两轮串行 MPS 训练、两个未微调基座对照，以及仅选定方案的封存测试。**没有可发布候选，不激活 Host，不替换旧权重。**

## 数据与实验约束

- glm-5.3-flash 共 96/96 次调用，全部完成，计 129,287 tokens。143 条审核记录（含恢复版本与争议重审）接受 89 条、拒收 54 条；这些记录不是 143 个独立故事。
- 冻结 train/dev/test 为 48/21/20 个场景家族，来自 20/12/11 个生成批次。每家族两个身份/候选顺序变体，因此各表示为 96/42/40 条。变体不充当独立样本。
- 两种表示使用相同场景、标签、切分和置换；只有回应选项从“由 M0 回应”改为“由姓名（M0）回应”。含昵称场景未经安全审核不改名。
- 每种表示全部 178 条训练输入与实际 SDK 投影逐 token/marker 一致，最长 626/651 tokens，无截断。全文重复检查及跨集合规范化用户文本 trigram Jaccard ≥ 0.65 检查未发现匹配；这不证明无语义重叠。
- 文本与标签来自 GLM，第二次标注看不到生成方向和原标签；助手只接受/拒绝，不改金标。同一教师的盲标注不能视为独立模型或独立人工验收。
- 两轮同基座、seed 71、4 epochs、batch 4、累积 2、最后 8 层、encoder/head LR 3e-5/1e-4、distribution CE+Brier 0.5。只保留两份新 checkpoint。按 dev 可接受准确率选 epoch，平局保留较早者；按 dev 切片宏平均选择表示。未调测试阈值或追加轮数。

## 一次封存测试

| 指标 | 同表示基座 | 选定 r6 |
|---|---:|---:|
| 可接受准确率 | 6/40，15.0% | 12/40，30.0% |
| 切片宏平均 | 13.3% | 30.0% |
| 最差切片 | 0% | 0% |
| 应停时误发言 | 4/10 | 7/10 |
| 应回应时漏回应 | 17/30 | 7/30 |
| 唯一成员选对 | 3/28 | 9/28 |
| 唯一成员误选其他人 | 10/28 | 13/28 |
| 置换后同一人物/动作 | 8/20 家族 | 11/20 家族 |
| 两变体都正确 | 1/20 家族 | 4/20 家族 |

逐条配对为修好 8、变坏 2、都对 4、都错 26；不把相关变体作独立显著性检验。固定首候选准确率为 27.5%，选定模型仅高 2.5 个百分点；固定 wait/finish 分别 5%/20%。提升相对弱基座存在，但远不足以证明可靠泛化。

选定模型按候选数 3/4/5/6 的结果为 6/16、2/10、4/8、0/6。5–6 人集中于星船世界及部分语义方向，不能把差异单独归因于人数。按家族重采样的描述性宏平均区间为 [16.7%, 44.2%]，未覆盖批内、同教师相关性或分布变化，不能当作上线置信界。

| 固定阈值 | 选定模型覆盖 | 正确 | 错误 |
|---|---:|---:|---:|
| 0.5 | 13/40 | 7 | 6 |
| 0.7 | 4/40 | 1 | 3 |
| 0.8 | 2/40 | 0 | 2 |
| 0.9 | 2/40 | 0 | 2 |

覆盖排除显式 abstain；上述是未经独立校准的 softmax 分数。两条高置信错误来自同一个家族的两个变体：用户明确允许人物互聊，当前角色又点名交棒，模型却输出 wait（0.9834/0.9991）。可能存在对“我听着”等表达的捷径依赖，但单一家族不足以判定原因。不能通过提高阈值宣称可靠。

全部四组 train/dev 及两组 test 共 632 条 SDK 回放通过协议校验；测试 r6 有 2 条达到 0.8 决策阈值，语义均错。**协议合法不等于语义正确。**测试回放中位延迟约 51 ms，仅为本机本轮观察。

## 对目标、指标和方向的修正

目标仍是人物在当前公开上下文中的下一步决策，不是按职业答题，也不是学习固定剧本。含姓名选项值得作为后续对照保留，但该实验只支持“本开发集更好”，没有证明表示改动本身在测试中优于原表示，因为另一表示按协议未测试。

当前不是仅靠增加 epoch 可以解释的问题：r6 训练只对 69.8%，训练应停也错 10/20，纯弃权错 4/4；开发 64.3% 到测试 30.0% 又暴露明显分布变化。基本边界未学好与泛化不足同时存在，不能只报告一个过拟合间隙。

下一轮应先修数据与诊断设计，具体协议见 [NEXT.md](NEXT.md)：

1. 把继续/停止、成员绑定、歧义弃权分别验收，保持宏平均但增加动作类别指标和原始混淆计数。每个关键子集必须有足够独立家族，否则标为未验证。
2. 生产改变一个决策事实就改变动作的对照家族；另设只改变姓名、顺序、世界、说法的等义家族。由 GLM 生成及盲标注，不本地写训练答案。拒收歧义无法消除的金标。
3. 人数、世界风格、动作和历史长度交叉覆盖，不能再让 5–6 人只出现在一种题材。降低“回复”占优所带来的捷径，先保证每类审核通过的独立家族数。
4. 先用新开发集比较一个明确干预，旧 v7 测试从现在起只能作已见诊断；新最终测试必须重新封存，不围绕这 40 条复训追分。

测试没有纯 abstain 金标，因同名歧义盲标注持续用职业推断而被拒收。因此**歧义弃权泛化未验证**，不能把同名题的覆盖当成已覆盖消歧能力。本轮也无独立置信度校准集，不提供自动回复放行依据。

# 实验记录（smart-home）

每一轮**先登记**（假设、唯一的改动、预期），再训练，训练后补结果。配方固定时一轮只改数据；改配方时数据不动。
数字口径：v1 = `evals/smart-home`（182，开发集）；v2-dev = v2 的 1/3（165，开发集）；v2-test = v2 的 2/3（335，测试集，只看汇总）。
决策指标见 `src/eidolon_laya_train/evaluate.py::decision_metrics`；区间是按记录重采样的 95% bootstrap。

## 固定配方（r3 起）

laya-multilingual（mmBERT-base 322M）起训；soft-CE + 0.5·Brier；每 epoch 打乱 choice / noul 选项；解冻最后 8 层；
lr 编码器 2.5e-5 / 头 1e-4，warmup 6%，3 epoch，batch 16；val NLL 选 best；按（题型, 选项数）分桶拟温度；Mac MPS。

## r9（登记）

- **假设**：误触发主要来自"对他人说话 + 设备名 + 祈使语气"和"家外面的感受"，训练数据里这两类只有几十条；
  补足这两类困难负例（并配同样句式但确实是对助手说的正例，防止矫枉过正）能把 v2-dev 误触发从 30% 降到 10% 以下，
  同时不降低控制召回。
- **唯一改动**：新增一批撰写数据（按 LABELING.md，10% 双人标注，清理与锁定集的近似重复）；配方、权重、外部数据不变。
- **预期**：v2-dev 误触发 ≤ 10%，自动执行精度 ≥ 95%；v1 / v2-dev 各切片不显著退步；控制召回（v2-dev 控制用例里意图判对的比例）不降。
- **数据**：b6-to-others 360 条（无关 260：对宠物 70 / 孩子 70 / 家人 60 / 自言自语 30 / 告诫 30；控制对照 100）、
  b6-outside-keep 400 条（家外面 120 无关 / 家里同类感受 100 控制 / 保持现状 90 无关 / 让运行中的设备停 50 控制 / 定时 vs 保持 40）。
  校验通过；与锁定集近似重复 0；**双人标注抽检 82 条（10%）：意图 / 设备 / 动作一致率 100% / 100% / 100%**
  （注意：两位标注者同为模型，一致率高估人工标注之间的一致性）；抽检暴露的 11 处规范空白已补进 LABELING.md 第 7 节。
- **结果**（训练 9,530 条，3 epoch，57 分钟）：

  | | r8 | r9 | 预期 | 结论 |
  |---|---|---|---|---|
  | v2-dev 误触发 无关→控制 | 30.3% | **12.1%** | ≤ 10% | 大幅下降，未完全达标 |
  | v2-dev 自动执行精度 @0.9 | 83.3% | **100%** | ≥ 95% | 达标（覆盖仅 18%，样本小） |
  | v2-dev 控制召回 | 97.4% | 97.4% | 不降 | 达标 |
  | 开发集配对门槛 vs r8 | — | PASS | 通过 | 达标；v2-dev 非命令 67% → 92%（修 7 坏 1） |
  | v1 意图 | 97.3% | 94.5% | — | 容差内（坏 6 修 1，p 0.06），需留意 |
  | **v2-test 误触发**（只看汇总） | 21.5% | 18.5% | — | **基本没转移**（65 条里 14 → 12，噪声内） |
  | v2-test 总准确率 / 控制端到端 / 自动执行精度 | 86.4 / 67.3 / 88.5% | 86.7 / 68.1 / 86.8% | — | 持平 |

- **结论**：假设在开发集上基本成立，但**提升没有转移到测试集**——数据是照着开发集里看到的误触发类型写的（对宠物孩子说话、家外面），
  模型学到了这些具体句式，没有学到"说话对象是谁"这个一般概念；测试集里的误触发是开发集没出现的类型。
  这正是开发 / 测试切分要暴露的问题。**教训：按概念造数据，而不是按开发集的例子造**；r10 的数据面更宽（别名、限定词、功能，覆盖 15 个户型），看它能否转移。

## r10（登记，数据在 r9 训练期间写）

- **依据**：r8 在开发集（v1 + v2-dev）上的 54 个设备题错误——
  ① 用别名 / 功能 / 位置指代**存在的**设备，模型选"没有"（19）："洗澡水" → 热水器、"过道" → 走廊感应灯、"放衣服那间" → 衣帽间灯、"电扇" → 落地扇；
  ② 房间 / 楼层限定词没用对（约 18）：限定的房间里没有这类设备却选了别的房间那台（"客厅那台加湿器"），或选错房间（"爸妈房间"、"二楼小卧室"）；
  ③ 一句话提到两台、其中一台被否定或保留，模型选"多个设备"（8）："书房的灯别关，把餐厅的关了"；
  ④ 功能错配（约 6）："脚底下好冰" → 冰箱。
- **假设**：这四类在训练数据里要么很少、要么没有成对的对照；补齐后设备题在开发集上从 77%（v2-dev）提升到 ≥ 85%，且"没有"出口不退步。
- **唯一改动**：在 r9 数据之上新增一批撰写数据（按 LABELING.md，只用训练户型，10% 双人标注，清理与锁定集的近似重复）；配方不变。
- **数据**：b7-alias-reference 350、b7-qualifier-negation 350、b7-function-match 200，共 900；与锁定集近似重复 0。
  撰写中发现早期 12 行把"都 / 全 / 两盏都"标成列表，按规范改为 `多个设备或整屋`（LABELING §8）。
  双人抽检 91 条：宽松一致（有交集）100%；严格一致（集合相同）设备 100% / 动作 86%，差异全是列表完整性，按并集裁决。
- **预期**：v2-dev 设备题 ≥ 85%；09（家里没有）、03（分房间）切片提升；误触发不回升。
- **结果**（训练 10,762 条，3 epoch）：

  | | r9 | r10 | 预期 | 结论 |
  |---|---|---|---|---|
  | v2-dev 设备题 | 73.5% | **78.8%** | ≥ 85% | 提升 5.3 点，未达标（修 13 坏 6） |
  | v2-dev 09 家里没有 / 03 分房间 | 82 / 78% | 87 / 80% | 提升 | 达标 |
  | v2-dev 误触发 | 12.1% | 12.1% | 不回升 | 达标 |
  | 开发集配对门槛 vs r9 | — | PASS | 通过 | 达标 |
  | **v2-test 总准确率 / 设备 / 控制端到端** | 86.7 / 77.8 / 68.1% | **88.5 / 80.7 / 72.1%** | — | 迄今测试集上提升最大的一轮 |
  | v2-test 自动执行 覆盖 / 精度 | 22% / 86.8% | 28% / 87.0% | — | 覆盖升，精度持平 |
  | v2-test 误触发 | 18.5% | 23.1% | — | 变差（65 条里 12 → 15） |

- **结论**：按概念造的数据（别名、限定词、功能，覆盖 15 个户型）**转移到了测试集**，和 r9 照例子造的数据形成对照。
  设备题未达 85%；误触发在测试集上仍是最大问题，留给 r11。
- **关于完成标准的可验证性**：v2-test 的自动执行样本约 40 条、无关样本 65 条——要确认"自动执行精度 ≥ 99%"需要数百条自动执行样本，
  "误触发 ≤ 2%"在 65 条上只允许错 1 条，区间都太宽。这两条暂作方向，最终验收需要更大的测试集（最好来自真实使用）。


## r11（登记；数据在 r10 训练期间写）

- **依据**：r9 的误触发改进没有转移到测试集（开发集 30% → 12%，测试集 21.5% → 18.5%）——数据是照开发集的例子写的。
- **假设**：误触发的根因是模型没学到"这句话是不是**对助手提出的请求**"这个概念。按**言语行为分类**系统覆盖（而不是按开发集例子），
  每类都配同框架的真请求对照，能让误触发下降**转移到测试集**。
- **分类**（每类都带设备名、多数带动作动词）：
  ① 说话对象不是助手：家人、客人、宠物、婴儿、电话 / 视频通话里的人、另一个语音助手；
  ② 引述 / 转述 / 朗读：电视剧台词、歌词、有声书、念消息、讲笑话、复述别人的话；
  ③ 非请求语气：愿望、假设、反事实、评价、叙述过去、抱怨但不要求；
  ④ 谈论助手本身：能力、回忆（"你昨天把灯关了"）、夸或骂；
  ⑤ 说自己要去做（"我去关灯"）；
  ⑥ 知识 / 价格 / 用法问题；
  ⑦ 对照组：同样框架但**确实**向助手提出请求（"电视里说要关灯省电，你也帮我关一下"）。
- **唯一改动**：在 r10 数据之上新增这批数据；配方不变。
- **数据**：b8-addressee-quote 360（说话对象 150 + 引述转述 110 无关、对照 100 控制）、b8-mood-meta 360（语气 110 + 谈论助手 60 +
  自己去做 50 + 知识 40 无关、对照 100 控制 / 查询）；与锁定集近似重复 0；双人抽检 62 条宽松 / 严格一致率均 100%；
  抽检暴露的 6 处规范空白已补进 LABELING §8（能力问题 vs 请求、第三方建议、唤醒名、"一般"类问题、窗帘动作）。
- **预期**：v2-test 误触发（只看汇总）从 18.5% 降到 ≤ 10%；v2-dev 误触发 ≤ 8%；控制召回不降。
